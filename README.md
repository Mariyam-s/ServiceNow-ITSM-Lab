# ServiceNow IT Support & ITSM Lab

## Overview

A simulated IT service desk environment built in ServiceNow to demonstrate practical ITSM and IT support workflows.

## Environment

- ServiceNow Personal Developer Instance
- Zurich release

## ITSM Areas Demonstrated

- Incident Management
- Request Management
- Assignment Groups
- Impact and Urgency
- Priority Management
- SLA Management
- Knowledge Management
- Service Catalog
- Reporting
- Dashboard

## Support Structure

- IT Support
- IT Operations
- Network Support

## Incident Scenarios

- Email authentication issue
- VPN connectivity issue
- Shared folder access
- Laptop performance issue
- Critical business application issue

## Knowledge Articles

- Troubleshooting Email Authentication Issues
- VPN Connection Troubleshooting
- Shared Folder Access Troubleshooting

## Service Catalog

- Request VPN Access

## Reporting

Created operational visualizations covering:

- Incidents by State
- Incidents by Priority
- Incidents by Assignment Group
- Incidents by Category

## Outcome

The lab demonstrates how an IT support environment can manage incidents, assign work, track service-level commitments, document solutions, handle service requests, and monitor operational data.
